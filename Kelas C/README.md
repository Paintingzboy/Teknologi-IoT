\# 📂 Direktori Project \& Tugas - Kelas B



Folder ini digunakan untuk mengumpulkan seluruh tugas individu, praktikum, dan project akhir dari mahasiswa \*\*Kelas B\*\*.



\## 📌 Ketentuan Penamaan Folder Project

Agar repositori tetap rapi, setiap mahasiswa/kelompok wajib membuat folder baru di dalam direktori `Kelas\_B/` dengan format penamaan berikut:



\* \*\*Tugas Individu:\*\* `\[NIM]\_\[Nama-Lengkap]`  

&#x20; \*Contoh:\* `2042241002\_Siti\_Nurhaliza`

\* \*\*Tugas Kelompok / Project Akhir:\*\* `Kelompok\_\[Nomor]\_\[Nama-Project]`  

&#x20; \*Contoh:\* `Kelompok\_02\_Automatic\_Watering\_System`



\## 📁 Struktur Isian Folder Project

Di dalam folder project masing-masing, pastikan memuat berkas berikut:

1\. 📂 `src/` (Source code program / sketsa Rust/Arduino/ESP-IDF)

2\. 📄 `README.md` (Penjelasan singkat cara kerja project, komponen hardware yang dipakai, dan skema rangkaian)

3\. 🖼️ `circuit/` atau `diagram/` (Foto alat atau gambar skema wiring)
