# 📑 Direktori Laporan Praktikum & Tugas Besar

Folder ini berisi arsip laporan resmi, modul panduan, serta berkas pendukung administrasi praktikum Teknologi IoT.

## 📁 Struktur Folder
* **`Modul_Praktikum/`** : Berisi file PDF petunjuk instruksi praktikum mingguan.
* **`Template_Laporan/`** : Format standar penyusunan laporan (.docx / .pdf).
* **`Pengumpulan_Laporan/`** : Folder arsip laporan resmi yang telah dinilai.

## 📌 Format Penamaan File Laporan
Setiap pengumpulan laporan wajib menggunakan format penamaan berikut:
* **Format:** `[Kelas]_[KodeModul]_[NIM/Kelompok]_[Nama].pdf`
* **Contoh (Individu):** `KelasA_Modul01_2042241001_AhmadFauzi.pdf`
* **Contoh (Kelompok):** `KelasB_TugasBesar_Kelompok03_SmartGreenhouse.pdf`

## ⚠️ Catatan Penting
* Laporan wajib dikumpulkan dalam format **PDF**.
* Dilarang mengunggah file mentah (*Word/RAW*) ke direktori pengumpulan utama kecuali diminta oleh Asisten/Dosen Pengampu.
